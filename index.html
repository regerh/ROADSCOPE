API 키를 설정하고 CCTV를 불러오세요

국가교통정보센터(ITS)에서 발급받은 본인 인증키가 필요합니다. 우측 상단 설정 버튼을 눌러 키를 입력한 뒤 '불러오기'를 눌러주세요.

CCTV 목록을 불러오는 중...

선택한 지역과 도로 유형에 해당하는 CCTV 데이터를 조회하고 있습니다.

정상 소통 정체 구간 위험 구간 사고 구간 실제 지도(OpenStreetMap/CARTO 타일) 위에 CCTV 위치를 실측 좌표로 표시합니다. ITS 실시간 소통정보·돌발정보 연동을 시도하며, 인근에서 실시간 데이터를 찾은 지점은 마커에 "실시간"으로, 찾지 못한 지점은 "추정"으로 표시됩니다(응답 스키마 미확인 시 자동 대체). 구간 선은 인접 CCTV를 이은 스케마틱 표시로 실제 도로 링크 형상과 다를 수 있습니다. 마커를 클릭하면 해당 CCTV 영상이 재생됩니다. ● 실시간 · ● 추정
데이터 출처: 국가교통정보센터(ITS) 공공 CCTV 개방데이터 · 본 사이트는 공개 API를 시각화하는 뷰어이며 영상을 저장하지 않습니다

⚙ 설정

인증키는 its.go.kr 회원가입 → 마이페이지 → 인증키 발급현황 → 인증키 신청 경로로 무료 발급받을 수 있습니다.

⚠️ 브라우저에서 직접 openapi.its.go.kr로 요청 시 CORS 정책으로 차단될 수 있습니다. 오류가 발생하면 하단 '프록시 안내'를 확인하세요. 키는 이 세션에서만 메모리에 보관되며 새로고침 시 사라집니다.
CORS 오류 발생 시
정적 HTML만으로는 우회할 수 없는 서버 정책일 수 있습니다. 이 경우 아래처럼 로컬 프록시 서버를 하나 두고, 이 파일의 API 호출 주소를 http://localhost:포트/cctvInfo로 바꿔 사용하세요. 
// proxy-server.js (node + express)
const express = require('express');
const app = express();
app.get('/cctvInfo', async (req, res) => {
  const url = 'https://openapi.its.go.kr:9443/cctvInfo?' +
    new URLSearchParams(req.query).toString();
  const r = await fetch(url);
  res.set('Access-Control-Allow-Origin', '*');
  res.json(await r.json());
});
app.listen(4000);
